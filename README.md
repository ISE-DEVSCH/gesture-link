# Gesture Link

카메라 영상에서 손동작·표정을 인식하고, 설정된 행동이 감지되면 사용자 승인 후 연결된 작업을 실행하는 Python 데스크톱 프로토타입입니다. FaceMesh의 468개 기본 얼굴 랜드마크와 refine landmark(홍채 포함)를 사용하며, 화면에 얼굴 테셀레이션을 표시합니다.

## 실행

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python app.py
```

## 웹 앱 실행

브라우저 버전은 [index.html](index.html)입니다. 카메라 권한 때문에 파일을 직접 더블클릭하기보다 작업 폴더에서 다음처럼 로컬 서버로 실행하세요.

```powershell
python -m http.server 8000
```

그 다음 브라우저에서 `http://localhost:8000/index.html`을 엽니다. MediaPipe 웹 번들·WASM·손 모델을 `web_deps` 폴더에 포함했으므로 로컬 서버에서 먼저 사용하며, 외부 CDN은 로컬 파일이 없을 때만 대체로 시도합니다. 카메라를 먼저 켠 뒤 손 모델을 불러옵니다. 엄지손가락 올리기, 손바닥 펴기, 양손 들기, 왼손, 오른손을 연결할 수 있습니다. URL 작업은 `URL 열기`로 통합했고, `앱 열기`는 `spotify://`, `steam://` 같은 커스텀 앱 프로토콜을 사용합니다. 손바닥 크기 대비 엄지 길이와 상승 각도, 다른 손가락 접힘을 함께 확인해 엄지 오탐을 줄였습니다. 손 모델은 GPU 초기화가 실패하면 CPU로 재시도합니다. 웹 브라우저 보안 정책상 일반 HTML은 Windows 프로그램을 임의로 실행할 수 없습니다.

카메라 시작 버튼을 누르면 인식이 시작됩니다. 행동 감지 후 확인창에서 **예**를 눌러야 작업이 실행됩니다. `행동 연결 편집` 탭에서 연결을 추가·수정·삭제하고 `설정 저장`으로 보관할 수 있습니다.

## 설정

`config.json`의 `actions` 배열을 수정합니다.

- `gesture`: `thumbs_up`, `both_hands_up`, `smile`, `wink`, `open_hand`, `mouth_open`, `brow_raise`
- `type`: `youtube`, `url`, `app`, `file`, `notification`
- `target`: 유튜브 URL, 웹 URL, 프로그램명, 파일 경로 또는 앱 내 알림 문구
- `cooldown_seconds`: 같은 행동의 반복 실행 방지 시간

실행 화면에는 손·얼굴·포즈 랜드마크가 함께 표시됩니다. 미소·윙크·입 벌리기·눈썹 올리기는 최근 여러 프레임을 평균 내어 한 프레임의 흔들림을 줄입니다.

`app` 유형은 사용자가 직접 수정한 로컬 설정을 실행하므로 신뢰할 수 있는 명령만 입력하세요. 현재 표정 인식은 조명과 카메라 각도에 따라 오탐이 생길 수 있는 휴리스틱 기반 프로토타입입니다.

## 중복 실행 방지와 우선순위

- `stable_frames`: 행동이 이 프레임 수만큼 계속 감지되어야 실행 후보가 됩니다. 기본값은 4입니다.
- `stable_frames_by_gesture`: 행동별 안정화 프레임입니다. 손동작은 3프레임, 표정은 4프레임으로 빠르게 반응합니다.
- `release_frames`: 한 번 실행한 뒤 행동이 해제되었다고 판단하기 위해 필요한 프레임 수입니다. 기본값은 5입니다.
- `cooldown_seconds`: 같은 연결의 재실행을 막는 시간입니다.
- 웹 앱 편집 화면의 `감지 유지 시간(ms)`은 인식 후 확인 요청까지 필요한 시간을 조절합니다. 값을 낮추면 빠르게 반응하고, 높이면 오탐이 줄어듭니다.
- `재실행 대기 시간(s)`은 같은 행동으로 다시 확인창을 띄우기까지의 대기 시간입니다.
- 동시에 여러 행동이 맞으면 `priority`가 가장 높은 연결 하나만 선택해 확인창을 띄웁니다. 편집 화면에서 우선순위를 설정할 수 있습니다.

미소는 입 너비뿐 아니라 입꼬리 상승량도 함께 확인하므로 중립 표정이나 말하는 동작의 오탐을 줄입니다. 손을 계속 들고 있거나 미소를 유지해도 작업 확인창이 반복해서 뜨지 않으며, 하나의 확인창이 처리되는 동안 다른 작업은 예약되지 않습니다.
